FLAME DRAGON HUB — Skin Bridge prototype (Chrome/Edge Manifest V3)

Install: unzip this project, open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select this extension folder.

Workflow: open Skin Studio in FLAME DRAGON HUB, design a skin, click Export for Extension, then open the extension popup and import the downloaded flame-dragon-skin.json. On evoworld.io the extension displays a local preview panel.

IMPORTANT: this is only the first integration bridge. It does NOT replace the avatar in the game yet. Exact local avatar replacement while preserving the game's animation requires inspecting and integrating with the live game's renderer/sprite pipeline; this prototype does not claim that behavior works.
