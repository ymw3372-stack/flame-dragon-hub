YOUR INSTALLATION ROADMAP

Up and running in a few simple steps

  1. 01
    Download the extension

    Get the latest FLAME DRAGON HUB ZIP package.

  2. 02
    Extract the ZIP

    Right-click the download and choose “Extract All”.

  3. 03
    Open Chrome Extensions

    Visit chrome://extensions in Chrome.

  4. 04
    Enable Developer mode

    Switch on Developer mode in the top-right corner.

  5. 05
    Load unpacked

    Select the extracted folder containing manifest.json.

  6. 06
    Pin and enjoy

    Pin FLAME DRAGON HUB, then open EvoWorld.
