Install the Chrome Extension

Follow these steps once to add FLAME DRAGON HUB to Chrome. This guide is for desktop Chrome on Windows, macOS, or Linux.

Step zero: Get the latest versionFLAME DRAGON HUB · Version 1.0.1 · ZIP file
DOWNLOAD v1.0.1 ↓
01

Download the ZIP file

Press the download button above and wait for FLAME_DRAGON_HUB_v1.0.1.zip to finish downloading. You can find it in your computer's Downloads folder.

02

Extract the ZIP file

Open your Downloads folder, right-click the ZIP file, then choose Extract All… and press Extract. Keep the extracted folder somewhere you can find later.

03

Open Chrome Extensions

Open Google Chrome, type this address in the address bar, and press Enter:

chrome://extensions
04

Turn on Developer mode

Find the Developer mode switch near the top-right corner of the Extensions page and turn it on. This lets Chrome load the extension folder you extracted.

05

Load the extension folder

Click Load unpacked. Select the extracted FLAME DRAGON HUB folder — choose the folder that contains manifest.json, then click Select Folder.

06

Pin it and start using it

Find FLAME DRAGON HUB in Chrome's Extensions menu (the puzzle-piece icon). Press the pin icon to keep it on your toolbar, then open EvoWorld and use the extension.

Quick check: If Chrome says it cannot find a manifest, you probably selected the wrong folder. Open the extracted folders until you see manifest.json, then select that folder itself. Do not select the ZIP file.

You're all set. Welcome to FLAME DRAGON HUB!

The extension is now added to Chrome. Keep the extracted folder in place; Chrome loads the extension from that folder.
