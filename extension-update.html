VERSION 1.0.3 · NETWORK ONLY

What changed?

  • The page-context scripts (page-bridge.js and content.js) are not included or registered.
  • The custom local-skin bridge is therefore unavailable in this build.
  • The extension retains its network-level image redirect functionality.
This change reduces one form of interaction with the game page. It does not guarantee that EvoWorld permits the extension or that an account cannot be restricted. Please check the game's rules and any reply from its team before using it.
OPEN GITHUB RELEASES ↗ INSTALLATION GUIDE

Download the asset named: FLAME_DRAGON_HUB_v1.0.3_NETWORK_ONLY.zip. The download will work after the repository owner publishes the v1.0.3 release and attaches that ZIP file.

How to replace the old ZIP version

  1. Close EvoWorld and open chrome://extensions.
  2. Find the old FLAME DRAGON HUB installation and choose Remove.
  3. Extract the v1.0.3 ZIP into a new folder that you will keep in the same location.
  4. Enable Developer mode, choose Load unpacked, and select the extracted extension folder.
  5. Open the extension and check that its version is 1.0.3.
Do not keep both versions enabled at the same time. Some local settings may not carry over when replacing an unpacked extension, so keep your old ZIP as a backup until you have checked the new installation.

Using Load unpacked already?

Replace the old installation with the extracted v1.0.3 folder, then use Load unpacked to load the new folder. If Chrome shows a duplicate extension, remove the old entry first. Confirm that only one FLAME DRAGON HUB installation is enabled.
